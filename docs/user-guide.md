# 使用指南

本文档面向使用和配置查看器的人，说明当前版本的界面、设置和实际行为。实现细节见[架构设计](architecture.md)和[设置字段参考](settings-reference.md)。

## 启动

```bash
npm install
npm run dev
```

默认打开：

```text
http://localhost:5173/
```

如果 5173 被占用，Vite 会自动选择下一个可用端口，以终端输出为准。

## 界面

当前版本是一个全屏画布：

- 画布常驻，占满窗口。
- 右侧是“播放设置”抽屉，默认关闭。
- 抽屉顶部有“Spine 模型”选择器，可搜索并切换模型。
- 右下角是眼睛按钮。
- 首次打开会显示“点击小眼睛可以打开设置”的提示气泡。
- 左上角是 `log` 按钮，点击展开调试信息。

当前**没有**编辑/展示模式，也没有 `?mode=show`。抽屉关闭时，点击画面可以直接触发 `action`（如果开关开启）。

## 打开和关闭设置

- 点击右下角眼睛按钮：打开/关闭抽屉。
- 点击提示气泡里的“我知道了”：关闭提示并打开抽屉；提示之后不再出现。
- 抽屉打开时，点击抽屉外的空白区域：关闭抽屉。
- 点击抽屉右上角“收起”：关闭抽屉。
- 没有 `Esc` 快捷键。

抽屉关闭时不可点击、不可聚焦（`inert`），不会误触里面的控件。

## 设置项

### Spine 模型

- 当前全模型包包含 128 个模型，标签使用目录名。
- 点击选择器会打开搜索框和模型列表，可以按目录名搜索。
- 选择后立即切换：旧模型卸载，新模型重新加载，缩放/位置/背景色保持不变。
- 每次刷新默认选择清单里的第一个模型；当前模型选择不会保存。
- 单模型包只有一项，选择器仍会显示。

### Spine 动画

下拉框列出当前骨架中可用的动画。当前资源只有：

- `idle` — 待机
- `action` — 动作

选择后立即播放：

- 选择 `idle`：循环播放。
- 选择 `action`：播放一次，结束后自动回到 `idle`。
- 如果动作正在播放时再次选择 `action`，会从头重播，并取消混合过渡。

### 点击画面触发 action

- 默认开启。
- 只有抽屉关闭时，点击画布才会触发 `action`。
- 鼠标左键、触摸或触控笔都可以触发。
- 抽屉打开时，点击画面区域只会关闭抽屉，不会触发 `action`。
- 取消勾选后，点击画面不会触发 `action`；当前动作会回到 `idle`。

### 缩放

- 范围：50%–500%。
- 默认：240%。
- 可以拖动滑杆、点击轨道、使用数字输入框，或点击 `−` / `+` 每次调整 1%。
- 输入框在按 `Enter` 或失去焦点时生效；超出范围会限制到 50%–500%。
- 放大到较高倍率时画面会被裁切，这是预期行为。

当前界面提示：Wallpaper Engine 中滑块拖动可能失效，可以直接点击轨道对应位置设置。

### 水平位置 / 垂直位置

- 范围：-100%–100%。
- 默认：水平 `-30%`，垂直 `-27%`。
- 单位是视口尺寸的百分比。
- 水平正值向右移动，垂直正值向下移动。
- 位置偏移会与缩放叠加；放大后移动同样的百分比，画面位移会更明显。

### 视图复位

抽屉里有两个复位按钮：

- “初始 100 / 0 / 0”：缩放 100%，水平 0%，垂直 0%。
- “推荐 240 / -30 / -27”：缩放 240%，水平 -30%，垂直 -27%。

它们只修改缩放和位置，不修改背景色或“点击画面触发 action”。

### 页面背景色

- 默认：`#06070d`。
- 可以使用预设色块、取色器，或直接输入 `#RRGGBB`。
- 颜色只作用于页面 CSS 背景；canvas 本身是透明的，所以颜色会出现在透明区域和缩放后的留白处。
- 输入无效色值时，失焦后会恢复为当前有效颜色。

## 调试信息

左上角 `log` 按钮可以展开/收起调试面板，显示：

- 运行环境（Wallpaper Engine / 浏览器）
- 浏览器版本
- 窗口、canvas、屏幕、可用屏幕尺寸
- 像素比
- CPU 线程、设备内存
- 平台、语言
- WebGL 版本 / vendor / renderer
- WE API 检测结果
- 页面 URL、User Agent

加载或运行错误会反映在 `log` 按钮的颜色和 `title` 上；当前没有全屏错误遮罩。

## 设置保存

当前版本**不会保存播放设置**：

- 缩放、位置、背景色、点击开关、当前动画和当前模型只存在于当前页面会话。
- 刷新页面后全部恢复默认值，并选择第一个模型。
- 唯一会保存的是“眼睛提示是否看过”，使用：

  ```text
  spine-viewer:eye-hint:v1
  ```

设置也不会写入 URL。

## 移动端

屏幕宽度不超过 640px 时：

- 设置抽屉占满整个屏幕宽度。
- 抽屉底部预留空间，避免被眼睛按钮遮挡。
- 主要通过眼睛按钮或点击抽屉外区域关闭设置。

## 当前版本不包含

- 模型选择持久化
- 编辑/展示模式切换
- `?mode=show`
- 播放速度
- 暂停/继续
- 循环 Action
- 自动播放
- 动画包围盒显示
- 设置持久化
- 全屏加载进度/错误遮罩

如果这些功能后续开发，需要同步更新本指南和[设置字段参考](settings-reference.md)。
