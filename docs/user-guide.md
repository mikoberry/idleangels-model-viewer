# 使用指南

本文档面向使用和配置查看器的人，说明两种模式、设置项和保存行为。实现细节见[架构设计](architecture.md)和[设置字段参考](settings-reference.md)。

## 启动

```bash
npm install
npm run dev
```

默认打开 `http://localhost:5173/`。开发服务器端口由 `vite.config.ts` 固定为 `5173`。

## 两种模式

### 编辑模式

编辑模式是默认模式，右侧显示“播放设置”抽屉，可以直接调整全部参数。

- 点击右下角眼睛按钮收起设置。
- 点击抽屉以外的任意区域收起设置。
- 按 `Esc` 在编辑模式和展示模式之间切换。
- 抽屉关闭后处于 `inert` 状态，不会接收焦点或点击。

### 展示模式

展示模式通过 `?mode=show` 打开，或从编辑模式收起设置后进入。

- 设置抽屉关闭，画面全屏展示。
- 进入展示模式时会播放“默认动画”。
- “自动播放”开启时立即继续；关闭时进入暂停状态。
- “点击画面触发 Action”开启时，点击画布会播放 `action`。
- 再次点击眼睛按钮或按 `Esc` 返回编辑模式。
- 展示模式是唯一写入 URL 的状态；设置本身不会写入 URL。

眼睛按钮默认透明度较低，鼠标移动到按钮附近时会自动变亮。

## 设置项

### 默认动画

选择进入展示模式时播放的动画。当前骨架提供：

- `idle` — 待机
- `action` — 动作

在设置中切换默认动画会立即播放该动画。若保存的动画在当前骨架中不存在，加载完成后会自动切换到第一个可用动画。

### 播放速度

- 范围：`0.25×`–`2×`
- 步进：`0.25×`
- 默认：`1×`

速度同时影响 `idle` 和 `action`。暂停状态下调整速度不会自动继续播放。

### 页面背景色

- 使用颜色选择器设置，右侧显示 `#RRGGBB` 色值。
- 默认：`#06070D`。
- 背景色显示在画面透明区域、图层透明部分以及缩放后的留白处。
- 颜色会立即应用到页面并持久化。

### 画面变换

#### 缩放

- 范围：`50%`–`500%`
- 默认：`100%`
- 可拖动滑杆，也可在百分比输入框中输入具体数值。
- 输入框在按 `Enter` 或失去焦点时生效；超出范围会自动限制到 `50`–`500`。
- 手动输入与滑杆双向同步。
- 放大到较高倍率时画面会被裁切，这是预期行为。

#### 水平位置 / 垂直位置

- 范围：`-100%`–`100%`，相对于视口尺寸。
- 默认：`0%`。
- 水平正值向右移动，垂直正值向下移动。
- 位置偏移会与缩放叠加生效。

### 播放与交互开关

#### 循环 Action

- 默认：关闭。
- 开启后，`action` 播放结束不会回到 `idle`，而是持续循环。
- 在 `action` 播放过程中切换该开关，会同步修改当前动画条目的循环状态。

#### 自动播放

- 默认：开启。
- 进入展示模式时，开启则立即播放，关闭则保持暂停。
- 编辑模式会恢复为非暂停状态。

#### 点击画面触发 Action

- 默认：开启。
- 仅在展示模式生效。
- 鼠标左键、触摸或触控笔点击画布会触发 `action`。
- 如果当前已经在播放 `action`，再次点击会从头重播并取消混合过渡。

#### 显示动画边界

- 默认：关闭。
- 开启后分别绘制 `bg` 和 `angel` 的动画包围盒。
- 边界基于 `idle` / `action` 的采样结果，不随当前帧实时变化。
- `bg` 和 `angel` 使用不同颜色区分。

### 预览

- “暂停 / 继续”切换当前播放状态。
- “触发 Action / 重播 Action”立即播放动作。
- 状态行显示当前动画以及 Action 是否播放中。

### 调试叠层

- 仅在编辑模式可见，且只在设置面板中手动开启。
- 显示 FPS、视口尺寸、相机 zoom、速度、当前动画、Action 状态。
- 资源加载完成后还会显示整体包围盒、图层版本、动画、皮肤、骨骼和插槽数量。
- 调试叠层是只读的，不接收鼠标事件。

### 恢复默认

“恢复默认”会把所有设置恢复到默认值，包括动画、速度、页面背景色、缩放、位置、开关和边界显示。

该操作会：

- 停止暂停状态
- 播放 `idle`
- 将设置写回 `localStorage`
- 不改变当前模式

## 设置持久化

设置保存在浏览器 `localStorage`，key 为：

```text
spine-viewer:playback:v1
```

行为：

- 每次设置变化后自动保存。
- 刷新页面后自动恢复。
- 无效或缺失的字段使用默认值。
- 存储内容解析失败时整体回退到默认设置。
- 浏览器禁用 `localStorage` 时仍可正常使用，只是不会保存。
- 展示模式状态不保存在 `localStorage`，只体现在 URL 的 `mode=show` 参数。

## 加载与错误

加载期间显示进度遮罩和百分比。资源路径、WebGL 或 Spine 数据出错时显示错误遮罩。

- 编辑模式下可直接修正设置或资源后刷新。
- 展示模式下错误遮罩会提供“返回编辑”按钮。

## 移动端

屏幕宽度不超过 `640px` 时：

- 设置面板占满整个屏幕宽度。
- 面板底部保留额外空间，避免被眼睛按钮遮挡。
- 眼睛按钮尺寸略小。
- 因为面板占满宽度，移动端主要通过眼睛按钮或 `Esc` 收起设置。
