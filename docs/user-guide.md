# 使用指南

本文档面向使用和配置查看器的人，说明当前版本的界面、设置和实际行为。实现细节见[架构设计](architecture.md)和[设置字段参考](settings-reference.md)。

## 启动

```bash
npm install
npm run dev      # 使用当前已准备的模型包
# 或：准备全部模型并启动
npm run dev:all
```

默认打开：

```text
http://localhost:5173/
```

如果 5173 被占用，Vite 会自动选择下一个可用端口，以终端输出为准。

## 界面

当前版本是一个全屏画布：

- 画布常驻，占满窗口。
- 右侧是“播放设置”抽屉：浏览器中默认打开，Wallpaper Engine 中默认收起；两种环境下都可用右下角眼睛按钮打开或关闭。
- 抽屉左侧是竖向标签菜单：Wallpaper Engine 中为**时间**、**频谱**、**模型**、**其它**；**浏览器中只有“模型”和“其它”**，时间与频谱依赖引擎的音频和媒体数据，浏览器里不显示这两个标签及其控件，**也不会显示时钟、频谱和专辑封面浮层**（即使当前模型预设里把它们设为显示）。菜单底部是语言按钮和“收起”按钮。上次打开的标签会被记住（浏览器里若上次停在时间/频谱，会自动回退到“模型”）。
- “Spine 模型”选择器**只在浏览器中显示**，Wallpaper Engine 中隐藏（引擎里始终使用清单中的第一个模型）。
- 右下角是眼睛按钮，用来打开或关闭抽屉。
- 左上角默认不显示调试信息；在设置抽屉“其它”标签勾选后才会出现。

当前**没有**编辑/展示模式，也没有 `?mode=show`。抽屉关闭时，点击画面可以直接触发 `action`（如果开关开启）。

## 打开和关闭设置

- 点击右下角眼睛按钮：打开/关闭抽屉。
- 抽屉打开时，点击抽屉外的空白区域：关闭抽屉。
- 点击抽屉左侧菜单底部的“收起”：关闭抽屉。
- 没有 `Esc` 快捷键。

抽屉关闭时不可点击、不可聚焦（`inert`），不会误触里面的控件。

## 设置项

以下设置都位于抽屉左侧标签菜单的对应标签里；语言按钮在菜单底部。

### 界面语言

- 支持简体中文、English、日本語、한국어。
- 默认跟随浏览器语言；无法识别时回退英文。
- 按钮位于抽屉左侧菜单底部，显示为“中 / EN / 日 / 한”。
- 语言保存在：
  ```text
  spine-viewer:language:v1
  ```

### Spine 模型（“模型”标签）

- 本地全模型包包含 332 个模型（127 个带背景的双层模型，205 个只有角色、没有背景的单层模型），GitHub Pages 线上版包含 50 个代表模型，标签使用目录名。
- 点击选择器会打开搜索框和模型列表，可以按目录名、拼音首字母、全拼或模型文件名搜索。
- 选择后立即切换：旧模型卸载，新模型重新加载，并应用该模型已记录的视图；没有记录时使用推荐缩放/位置/背景色，仍没有则回到 100 / 0 / 0 和黑色。
- 每次刷新默认选择清单里的第一个模型；当前模型选择不会保存。
- 单模型包只有一项，选择器仍会显示。

### Spine 动画（“模型”标签）

下拉框列出当前骨架中可用的动画。当前资源只有：

- `idle` — 待机
- `action` — 动作

选择后立即播放：

- 选择 `idle`：循环播放。
- 选择 `action`：播放一次，结束后自动回到 `idle`。
- 如果动作正在播放时再次选择 `action`，会从头重播，并取消混合过渡（下拉框是显式操作，不受“点击需等待播完”的限制）。

### 点击画面触发 action（“模型”标签）

- 默认开启。
- 只有抽屉关闭时，点击画布才会触发 `action`。
- 鼠标左键、触摸或触控笔都可以触发。
- **`action` 播放期间再次点击画面会被忽略**，必须等当前动作播完、回到 `idle` 后才能触发下一次。快速连点不会打断或叠加动作。
- 抽屉打开时，点击画面区域只会关闭抽屉，不会触发 `action`。
- 取消勾选后，点击画面不会触发 `action`；当前动作会回到 `idle`。

### 缩放（“模型”标签）

- 范围：50%–500%。
- 默认：当前模型推荐值；没有推荐时 100%。
- 可以拖动滑杆、点击轨道、使用数字输入框，或点击 `−` / `+` 每次调整 1%。
- 输入框在按 `Enter` 或失去焦点时生效；超出范围会限制到 50%–500%。
- 放大到较高倍率时画面会被裁切，这是预期行为。

当前界面提示：Wallpaper Engine 中滑块拖动可能失效，可以直接点击轨道对应位置设置。

### 水平位置 / 垂直位置（“模型”标签）

- 范围：-100%–100%。
- 默认：当前模型推荐值；没有推荐时水平 `0%`、垂直 `0%`。
- 单位是视口尺寸的百分比。
- 水平正值向右移动，垂直正值向下移动。
- 位置偏移会与缩放叠加；放大后移动同样的百分比，画面位移会更明显。

### 视图复位（“模型”标签）

抽屉“模型”标签里有四个视图相关按钮：

- “初始 100 / 0 / 0”：缩放 100%，水平 0%，垂直 0%；不修改背景色。
- “推荐 …”：应用当前模型的推荐缩放、位置和推荐背景色。
- “记录当前视图”：把当前模型和当前缩放/位置/背景色记录到浏览器。
- “复制全部视图”：只把已经记录过的模型一次性复制成 JSON，可直接粘贴到 `model-presets.json`。

“推荐”没有配置时会回到 100 / 0 / 0 和黑色背景。

### 页面背景色（“模型”标签）

- 默认：当前模型推荐背景色；没有推荐时黑色 `#000000`。
- 可以使用预设色块、取色器，或直接输入 `#RRGGBB`。
- 颜色只作用于页面 CSS 背景；canvas 本身是透明的，所以颜色会出现在透明区域和缩放后的留白处。
- 输入无效色值时，失焦后会恢复为当前有效颜色。

## 音频频谱（“频谱”标签）

抽屉的“频谱”标签可以打开屏幕边缘的柱状频谱：

- 勾选“显示音频频谱”后出现柱状频谱，随音频跳动（共 128 根柱子）。
- **样式**：9 种——经典竖条、镜像柱、曲线波形、胶囊柱、环形柱状、环形波形、LED 点阵、声波涟漪、极光。
- **水平位置**：0%–100%，单位是窗口宽度的百分比，50% 为居中。
- **垂直位置**：0%–100%，单位是窗口高度的百分比，50% 为居中。
- **缩放**：20%–500%，默认 300%，控制整块频谱的大小；支持滑杆、输入框和 ±1% 步进。100% 是控制件的基准盒（条形约 30vw × 15vh），300% 约等于旧版的“铺满宽度”。
- **颜色**：与页面背景色使用同一套取色器（预设色块、色域、色相条、`#RRGGBB` 输入），默认 `#a8c4ff`。
- Wallpaper Engine 中响应系统正在播放的音乐（含其它播放器）；音乐停止后柱状图会**静止**，不会自行跳动。
- **浏览器中不显示频谱**（读不到系统音频，也不会用假数据凑数）。
- 频谱不拦截鼠标点击，开着它仍然可以点击画面触发 `action`。
- 如果 Wallpaper Engine 里发现柱子不跟音乐，打开抽屉的「其它」→「显示调试信息」，查看「音频数据」一行：
  - `非 WE 环境，无音频数据`：当前不在引擎内。
  - `已注册，等待音频数据`：引擎没有推送音频，检查 WE 设置中的 playback/recording 设备与音量。
  - `接收中`：正在接收真实音频。

## 专辑封面（“频谱”标签）

同一个“频谱”标签下方还有**专辑封面**卡片，显示 Wallpaper Engine 媒体信息里的封面、曲名、艺术家和专辑名：

- 勾选“正在播放”开关后出现卡片；**没有音乐时卡片整块消失**（不再显示“暂无播放中的音乐”提示）。
- **样式**：6 种——经典原版、玻璃卡片、黑胶唱片、极简文字、信息条、封面墙。
- **大小**：占屏幕高度的 10%–40%，默认 18%。
- **水平/垂直位置**：0%–100%，从视口**左边和底边**向内测量；默认水平 64% 让卡片落在右下角附近。四角锚定已取消，所有控件统一按左下角定位。
- 封面是圆形遮罩，每 24 秒转一圈；音乐暂停时停止旋转。
- 卡片里的小频谱跟随“音频频谱”的颜色设置。
- 需要在 Wallpaper Engine 设置中开启**媒体集成**，否则不会收到任何媒体信息。
- 部分播放器不提供播放状态；只要引擎没报告“已停止”，封面就会一直保留，不会因为歌曲时长过长而消失。

## 时间与日期（“时间”标签）

抽屉的“时间”标签可以打开当前时间与日期显示：

- 勾选“显示当前时间与日期”后，画面上出现时钟；取消勾选立即消失。
- 时钟没有背景色块，文字直接浮在画面上，只有一层柔和投影保证可读。
- 默认在**左边距 10%、垂直居中**的位置，字号较大，便于远距离读取。
- 版式共 9 种：极简数显、赛博朋克、横向状态条、双行分层、大字海报、竖排经典、横排经典，以及两种用图形表达时间的**环形进度**（外环一天、内环一小时）和**分段进度**（时/分/秒各一条）。
- 可以调整：
  - **大小**：40%–200%，默认 100%；支持滑杆、输入框和 ±1% 步进。
  - **水平位置**：0%–100%，单位是窗口宽度的百分比，正值向右。
  - **垂直位置**：0%–100%，单位是窗口高度的百分比，正值向上。
- **跟随鼠标摆动**：鼠标在整个屏幕上移动时，时钟会平滑地渐进倾斜——指向右上角时右上角翘起、左下角沉下，指向左下角时相反。鼠标移出窗口后恢复平放。
- 时间制式可在抽屉里切换 24 / 12 小时；点击时钟本身也能切换。日期与周几跟随界面语言变化，始终显示具体年月日。
- 刷新页面后会记住开关、版式、大小和位置，保存在 `spine-viewer:clock:v1`。
- 时钟不拦截鼠标点击，所以开着时钟时点击画面仍然可以触发 `action`。
- 系统开启“减少动态效果”时，摆动效果自动关闭。
- **随音频节拍律动**：勾选后时钟会随低频轻微放大并泛起光晕。
  - 下方“响应强度”滑杆（0%–1000%，默认 100%）控制律动的幅度；0% 时看不出反应，1000% 最强。
  - Wallpaper Engine 中响应系统正在播放的音乐（含其它播放器）。
- Wallpaper Engine 中壁纸暂停后恢复，时钟会立即更新，不会停在旧时间。

## 调试信息（“其它”标签）
在设置抽屉“其它”标签里勾选“显示调试信息”，左上角会直接出现调试窗口；取消勾选窗口立即消失。窗口显示：

- 运行环境（Wallpaper Engine / 浏览器）
- 浏览器版本
- 窗口、canvas、屏幕、可用屏幕尺寸
- 像素比
- CPU 线程、设备内存
- 平台、语言
- WebGL 版本 / vendor / renderer
- WE API 检测结果
- 页面 URL、User Agent

加载或运行错误会显示在调试窗口顶部的“状态”行和抽屉的状态行里；当前没有全屏错误遮罩。

## 设置保存

当前版本**不会自动保存全局播放设置**：

- 缩放、位置、背景色、点击开关、当前动画和当前模型只存在于当前页面会话。
- 刷新页面后选择第一个模型；未记录的视图恢复默认值。
- 点击“记录当前视图”后，模型视图会保存到：
  ```text
  spine-viewer:model-views:v1
  ```
- 以下显示偏好**会自动保存**并在刷新后恢复：
  ```text
  spine-viewer:clock:v1        # 时间与日期
  spine-viewer:spectrum:v1     # 音频频谱
  spine-viewer:album-art:v1    # 专辑封面
  spine-viewer:drawer-tab:v1   # 抽屉上次打开的标签
  ```
- 界面语言保存到：
  ```text
  spine-viewer:language:v1
  ```

设置也不会写入 URL。

## 移动端

屏幕宽度不超过 640px 时：

- 设置抽屉占满整个屏幕宽度。
- 左侧标签菜单改为顶部横向排列。
- 抽屉底部预留空间，避免被眼睛按钮遮挡。
- 主要通过眼睛按钮或点击抽屉外区域关闭设置。

## 当前版本不包含

- 模型选择持久化
- 编辑/展示模式切换
- `?mode=show`
- 播放速度
- 暂停/继续
- 循环 Action
- 自动播放
- 动画包围盒显示
- 全局播放设置持久化（`scale` / `positionX` / `positionY` / `backgroundColor` / `clickToAction`）
- 全屏加载进度/错误遮罩

如果这些功能后续开发，需要同步更新本指南和[设置字段参考](settings-reference.md)。
